# Python 量化评审清单

> lean-review 的技术栈补充。检测到 pyproject/requirements 含 vectorbt/pypfopt/akshare/pandas/numpy 时加载。
> 按严重度预分级：⚠️ = 通常 Critical，◆ = 通常 Major，· = Minor。

## 回测正确性（最高危区）

- ⚠️ **前视偏差**：T 日信号用了 T 日及之后的数据（shift 对齐、rolling 窗口边界、未来函数）
- ⚠️ 成交价假设不现实：信号日收盘价成交、无滑点/手续费、流动性无限
- ⚠️ 幸存者偏差：股票池/ETF 列表用的是今天的成分，不是历史时点
- ◆ 再平衡逻辑与声明的周期/阈值不一致（代码漂移）
- ◆ 权重归一化时机错误；优化器失败静默回退（必须显式抛出或记录）

## 数据管道

- ⚠️ 真实数据源（akshare/baostock）调用混入计算核心层，无法测试无法缓存
- ◆ 时区/日历未对齐就合并多源数据（A股 vs 美股交易日不同）
- ◆ NaN 处理隐式：`dropna()`/`fillna(0)` 吞掉数据质量问题，应有缺口率断言
- ◆ 复权口径混用（前复权/后复权/不复权在同一计算里）
- · 数据缓存无失效策略（stale 数据静默使用）

## 数值

- ⚠️ 货币金额用 float 累加（应用 Decimal 或显式精度策略）
- ◆ 除法未防零（波动率=0、持仓=0）
- ◆ 收益率口径：简单/对数混用；年化系数硬编码 252 未按市场调整
- · 浮点相等断言（应 np.isclose）

## 优化 / ML

- ⚠️ 参数在全样本上调优后宣称样本外有效（过拟合；应有 walk-forward 断言）
- ◆ sklearn Pipeline 在划分训练/测试前 fit（泄漏）
- ◆ 随机算法未钉 seed，结果不可复现
- · 优化约束（权重上下限、做空）只在文档里没进代码

## 测试

- ◆ 测试里真实调用数据源（应 fixture/mock）
- ◆ 无确定性：随机数据无 seed、时间依赖未冻结
- · 全量历史回测跑在单元测试里（应小窗口 + slow 标记分层）
