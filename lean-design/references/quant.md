# 量化投资领域问题库

> lean-design 的领域补充。检测到量化项目（vectorbt/pypfopt/akshare 等）时，把下列问题作为批量澄清的候选前沿——按任务选用，不必全问；每题仍附你的推荐答案。

## 策略与组合

- 优化方法：MVO / 最小方差 / 风险平价 / 等权？（推荐：风险平价——对估计误差最鲁棒；MVO 对预期收益假设极敏感）
- 约束：权重上下限？允许做空？单资产上限？（推荐：0-60%，禁做空）
- 基准与评估指标：夏普/卡玛/最大回撤/年化？以谁为基准？
- 预期收益与协方差的估计窗口和方法？（推荐：协方差用 Ledoit-Wolf 收缩，预期收益尽量避免点估计）

## 回测与验证

- 样本内/外如何划分？walk-forward 窗口（滚动 vs 扩展、长度、步长）？
- 过拟合预算：允许调几个参数？OOS 衰减多少以内可接受？（推荐：夏普衰减 <50%）
- 成交假设：价格（次开盘价？）、滑点、手续费、最低交易额？
- 股票池时点性：成分列表是历史时点还是今天？（防幸存者偏差）

## 再平衡

- 周期（月/季）还是阈值（漂移 5%）触发，还是双触发？
- 部分再平衡（只回阈值内）还是全量回目标？
- 交易成本怎么计入决策？

## 数据管道

- 主数据源与降级链：akshare → baostock → 缓存？数据缺口策略（前向填充上限/直接报错）？
- 复权口径：前复权用于收益计算，不复权用于信号？在哪一层统一？
- 时区与交易日历：跨市场资产在哪一层对齐？（推荐：统一 UTC + 各市场日历 join）

## 数值与工程

- 金额精度策略：Decimal 还是 float+容差？在哪一层转换？
- 结果缓存与失效：回测结果缓存的 key 是什么（数据版本+参数哈希）？
- 失败语义：优化器不收敛/数据缺口超阈值时，抛出、回退还是跳过？（推荐：显式抛出 + 报告标注）
