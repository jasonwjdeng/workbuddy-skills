# Lean Debug — 先回路，后修复

**铁律：没有根因，不动手修。症状式修复 = 失败。** 各阶段必须按序完成，跳阶段要有明确理由。

## 技术栈检测（Phase 1 前，一次性）

扫描栈标记（`pom.xml`/`build.gradle` → `references/java-spring-boot.md`；quant 依赖 → `references/python-quant.md`），命中则加载——里面有栈内的回路构造优先序、假设边界插桩点和诊断工具（OOM 决策树、pg_stat_statements、pandas 索引对齐坑等）。未命中 → 跳过。

## Phase 0：脱敏红线

展示命令、输出、抓取的报文之前，先把密钥写成 `<REDACTED>`；回路脚本用环境变量读凭据，别把凭据写进脚本和展示内容。脱敏后不足以定位时，明说并向用户要。

## Phase 1：建反馈回路（本 skill 的核心）

**有一个能对这个 bug 变红的紧回路，根因迟早现形；没有它，盯再久代码也没用。** 在这里投入不成比例的精力。构造方式按此顺序选：

1. 失败测试（单测/集成/e2e，哪个接缝够得着用哪个）
2. curl / HTTP 脚本打本地服务
3. CLI + fixture 输入，diff 标准输出
4. 无头浏览器脚本驱动 UI 断言
5. 重放抓取的请求/报文/事件
6. 一次性最小 harness（mock 依赖，单函数调用复现）

**收紧回路**：能跑快吗（秒级）？信号够锐吗（断言具体症状，不是"没崩"）？确定吗（钉时间/随机种子/隔离文件系统）？agent 能无人值守跑吗？
**非确定性 bug**：目标是提高复现率——循环 100 次、加压、窄化时间窗；50% 可复现就能调，1% 不能。
**建不出来**：停下，明说，列出试过的方案，向用户要三样之一：能复现的环境访问、脱敏的抓取件（HAR/日志/core dump/带时间戳录屏）、或生产临时插桩授权。**没有红回路，禁止进入假设。**

**完成判据**：一条你已跑过至少一次的命令（展示脱敏后的调用与输出），且它是 red-capable（断言用户的精确症状）+ 确定性 + 秒级 + agent 可跑。发现自己没建回路就开始读代码建理论——**停下，这正是本 skill 要防的失败**。

## Phase 2：复现 + 最小化

跑回路，看它红。确认失败模式就是用户描述的那个（修错 bug = 修错方向）。然后逐个删输入/调用方/配置/数据，每次删完重跑，**直到每个剩余元素都承重**——删掉任何一个回路就变绿。最小复现直接成为 Phase 5 的回归测试。

## Phase 3：假设

生成 **3-5 个可证伪假设并排序**，不许单假设锚定。每个必须带预测：

> 格式："如果 X 是根因，那么改动 Y 会让 bug 消失 / 改动 Z 会让它更严重。"

说不出预测的就是直觉，丢弃或磨锐。**把排序列表给用户看一次**（不阻塞）：用户常有领域知识能瞬间重排（"#3 刚改过"）或排除已验证项。

## Phase 4：插桩

每个探针对应 Phase 3 的一个具体预测，**一次只动一个变量**。优先级：断点/REPL > 定向日志（打在区分假设的边界）> 绝不"全量日志再 grep"。每条调试日志打唯一前缀 `[DEBUG-xxxx]`，清场一次 grep 删净。**性能分支**：日志通常是错的——先建基线测量（计时/Profiler/查询计划），再二分。先量后改。

## Phase 5：修复 + 回归测试

**只有存在正确接缝时才先写回归测试**——测试能按真实调用方式复现 bug 模式；接缝太浅（单调用方/断链）的测试只给虚假信心。**没有正确接缝本身就是发现**：架构让这个 bug 锁不住，记下来回流给设计流程。有接缝则：最小复现 → 失败测试 → 看它红 → 修复 → 看它绿 → **用 Phase 1 回路对原始（未最小化）场景重跑**。

## Phase 6：清场（宣布完成前的必查清单）

- [ ] 原始场景重跑 Phase 1 回路，不再复现
- [ ] 回归测试通过（或"无正确接缝"已书面记录）
- [ ] 所有 `[DEBUG-...]` 日志已 grep 删净
- [ ] 一次性原型已删除或移入明确标注的 debug 目录
- [ ] 被证实的假设写进 commit message，让下一个排障者受益

## Red Flags

| 念头 | 现实 |
|------|------|
| "我知道哪错了，直接改" | 那是假设。先建红回路 |
| "改完了，看起来好了" | 跑回路验证原始症状。症状消失 ≠ 根因找到 |
| "日志全加上再 grep" | 一次一个变量，打在假设边界上 |
| "复现不了，先这么改着" | 建不出回路就停下说，不许猜着修 |
| "测试全绿了" | 绿 ≠ 回路能红。没有红回路就没有排障 |
| "修完就完事" | 清场清单不过，不算完 |
